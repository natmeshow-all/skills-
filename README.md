# ระบบบริหารและพัฒนาทักษะช่าง (Technician Competency & Development Portal)

เว็บแอปพลิเคชันสำหรับ **หัวหน้าช่าง (Lead Technician / Maintenance Supervisor)** ใช้จัดเก็บข้อมูลพนักงานช่าง ประเมิน Skill Matrix ติดตามการสอนงานช่างใหม่ (OJT 30-60-90 วัน) และวิเคราะห์สมดุลทักษะประจำกะ

---

## วิธีเปิดใช้งาน (ง่ายมาก เลือกได้ 2 วิธี)

### วิธีที่ 1: ดับเบิลคลิกไฟล์ HTML โดยตรง (แนะนำ - รวดเร็วที่สุด)
- ดับเบิลคลิกที่ไฟล์ `index.html` เพื่อเปิดใช้งานบน Google Chrome, Microsoft Edge หรือ Firefox ได้ทันที โดยไม่ต้องติดตั้งโปรแกรมใดๆ เพิ่มเติม

### วิธีที่ 2: รันผ่าน Web Server (สำหรับเปิดใช้งานในวง LAN หรืออุปกรณ์มือถือ/แท็บเล็ต)
- ดับเบิลคลิกที่ไฟล์ `start_server.bat`
- ระบบจะเปิดเบราว์เซอร์ไปที่ `http://localhost:8080` โดยอัตโนมัติ

---

## ฟังก์ชันเด่นของระบบ

1. **แดชบอร์ดภาพรวม (Dashboard):**
   - สรุปจำนวนช่าง, สัดส่วนช่างระดับชำนาญการ (L3-L4), ช่างใหม่ที่กำลังฝึก OJT
   - กราฟใยแมงมุม (Radar Chart) แสดงสมดุลทักษะเฉลี่ย 6 ด้านของทีม
   - กราฟโดนัทแสดงสัดส่วนระดับฝีมือช่าง L1 ถึง L4

2. **ระบบทะเบียนพนักงานช่าง (Technician Roster):**
   - ค้นหาตามชื่อ, รหัส, แผนก, กะ หรือระดับฝีมือ
   - เพิ่ม/แก้ไข/ลบ ข้อมูลช่าง พร้อมบันทึกเบอร์โทร, พี่เลี้ยง (Mentor), วันเริ่มงาน และเป้าหมายพัฒนา

3. **ตารางประเมินทักษะ (Interactive Skill Matrix):**
   - คลิกเพื่อเปลี่ยนระดับทักษะ L1, L2, L3, L4 ได้ทันที
   - ระบบคำนวณคะแนนเฉลี่ยอัตโนมัติ
   - ปุ่มส่งออกเป็นไฟล์ Excel (CSV)

4. **แผนติดตามการสอนงานช่างใหม่ (OJT 30-60-90 Days Roadmap):**
   - เลือกลูกทีมที่กำลังฝึกงาน
   - ติ๊กถูกผ่านการประเมินแต่ละระยะ (30 วัน, 60 วัน, 90 วัน)
   - ดูสรุปความพร้อมก่อนขึ้นเวรเดี่ยว

5. **ระบบตรวจสอบสมดุลกะทำงาน (Shift Redundancy Analysis):**
   - เช็กความพร้อมของแต่ละกะ (กะเช้า, กะบ่าย, กะดึก, กะปกติ)
   - แจ้งเตือนสีแดงทันทีหากกะไหนขาดช่างระดับ L3 หรือ L4 (ด้านไฟฟ้าหรือเครื่องกล)

6. **ระบบสำรองข้อมูล (Data Backup & Restore):**
   - ข้อมูลจะถูกบันทึกไว้ในเบราว์เซอร์ของคุณอย่างปลอดภัยแบบอัตโนมัติ (ปิดเครื่องข้อมูลไม่หาย)
   - สามารถกดสำรองเป็นไฟล์ JSON หรือดาวน์โหลดเป็นไฟล์ Excel (CSV) ได้ตลอดเวลา
